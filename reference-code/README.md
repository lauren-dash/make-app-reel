# Reference code from one past reel (TODOOM)

Working code for the techniques in `skill/make-app-reel/references/technique.md`: filming
screens frame by frame, made-up data, filming the build chat safely, an HTML end card,
cutting pauses, captions, synthesised sound and the final edit. It is full of TODOOM-specific
paths, timings, crops and ports.

Reuse the techniques. Don't reuse the content: the script, shot choices, captions style,
end card design, music and sound effects should all be made new for each app.
`sound.py` in particular shows *how* to synthesise music; compose a new piece each time.
