# Make a reel about an app you built in Studio

A short vertical video (Reels / TikTok / Shorts) about something you built in Studio: you
talking to camera, the prompt you typed, the app doing its thing, captions, and music Studio
writes for you. It should feel like a friend showing you something cool, not an ad.

**The point of the reel, in order:**
1. Show how easy it was to build with Studio. Your prompt is the star.
2. Show off the app.

You do three things: answer a few questions about your app, film one take of yourself, and
watch the result. Studio does the rest.

## Start

1. Download this repo (green **Code** button, then **Download ZIP**).
2. Open a Studio chat in the workspace where your app lives (ideally where the chat you
   built it in still exists).
3. Attach the `skill/make-app-reel` folder to the chat and paste the first prompt from
   `prompts.md`. (Or just paste this repo's link and ask Studio to install the skill from it.)
4. Follow along; `prompts.md` has the few prompts you'll need after that.

## What's in here

| | |
|---|---|
| `prompts.md` | The prompts to paste, in order. Start here. |
| `skill/make-app-reel/` | The instructions Studio follows. Studio installs it; you don't need to read it. |
| `reference-code/` | Code from one past reel, so Studio can reuse its techniques (filming screens, captions, sound). Not a template: your reel gets its own script, look and music. |
| `example-reel.mp4` | One past reel (TODOOM). Watch it for the level of polish, not the format; yours should be built around your own app. |

## Tips

- **Think about the fun part.** Studio will ask what the most interesting thing about your
  app is, and what was the easiest or most fun part of building it. Those answers make the reel.
- **Your real data never goes on screen.** Studio films a private copy of your app on
  made-up data.
- **One take is enough.** Keep going through stumbles; Studio cuts pauses and "um"s without
  clipping your words.
- **Watch with sound on** before you share it. Studio can't hear.
